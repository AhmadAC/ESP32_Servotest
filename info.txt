1. SERVO MOTOR WIRING (CLAW ACTUATOR):
--------------------------------------------------------------------------------
Servo Lead      Color (Typical)     YD-ESP32-S3 Pin     Notes
GND             Black / Brown       GND                 Common Ground
VCC             Red                 5V / VBUS           Power from 5V (USB or external supply)
Signal (PWM)    Orange / Yellow     GPIO 4 (GP4)        50Hz LEDC hardware PWM signal


2. HT517 I2S AMPLIFIER WIRING (V1.0.2 SILKSCREEN):
--------------------------------------------------------------------------------
HT517 Pin       Function            YD-ESP32-S3 Pin     Notes
Vin             Power Supply        5V / 3.3V           5V recommended for full volume
GND             Ground              GND                 Common Ground
EN              Enable / Mute       NC (Unconnected)    Internal pull-up; leave floating
GAIN            Gain Select         NC (Unconnected)    Floating for default gain
DI2             Serial Data (DIN)   GPIO 12             I2S Audio Data Stream
DIO (DI0)       Bit Clock (BCLK)    GPIO 10             I2S Channel 0 Clock
DI1             Word Select (LRC)   GPIO 11             I2S Left / Right Frame Sync


3. PS2 JOYSTICK & BUTTON MODULE WIRING (ANALOG GAMEPAD BREAKOUT):
--------------------------------------------------------------------------------
Joystick Pin    Function            YD-ESP32-S3 Pin     Internal Config
VCC             Supply (3.3V/5V)    3.3V (Recommended)  Potentiometer reference
GND             Ground              GND                 Common Ground
VRX             X-Axis Potentiometer GPIO 1              ADC1 Channel 0 (Claw Angle 0-180 deg)
VRY             Y-Axis Potentiometer GPIO 2              ADC1 Channel 1 (Pitch / Fine Adjust)
SW              Joystick Push Key   GPIO 3              Input with Internal Pull-Up (Auto-Retract Toggle)
K1 (Red)        Tactile Button 1    GPIO 5              Input with Internal Pull-Up (Open 180 deg)
K2 (Green)      Tactile Button 2    GPIO 6              Input with Internal Pull-Up (Center 90 deg)
K3 (Blue)       Tactile Button 3    GPIO 7              Input with Internal Pull-Up (Bark Sound)
K4 (Yellow)     Tactile Button 4    GPIO 8              Input with Internal Pull-Up (Test Beep Tone)

* Operation:
- Moving VRX smoothly controls the claw position from 0 to 180 degrees.
- When Auto-Retract is ON, releasing the joystick back to center snaps the claw to 0 degrees.
- Pressing SW toggles Auto-Retract on/off.
- The 4 tactile buttons provide instantaneous one-touch control with hold-to-open capability.


4. 16-KEY MATRIX KEYBOARD WIRING (4x4 CLAW KEYPAD):
--------------------------------------------------------------------------------
Keypad Lead     Function            YD-ESP32-S3 Pin     Internal Config
Row 1 (R1)      Row Scan 1          GPIO 13             Output (Active LOW)
Row 2 (R2)      Row Scan 2          GPIO 14             Output (Active LOW)
Row 3 (R3)      Row Scan 3          GPIO 15             Output (Active LOW)
Row 4 (R4)      Row Scan 4          GPIO 16             Output (Active LOW)
Col 1 (C1)      Column Read 1       GPIO 17             Input (Internal Pull-Up)
Col 2 (C2)      Column Read 2       GPIO 18             Input (Internal Pull-Up)
Col 3 (C3)      Column Read 3       GPIO 21             Input (Internal Pull-Up)
Col 4 (C4)      Column Read 4       GPIO 38             Input (Internal Pull-Up)

Matrix Key Coordinates and Factory Defaults:
- Key 1  (R1C1): '0'         -> Close Claw Completely (0 deg)
- Key 2  (R1C2): '45'        -> Claw Quarter Open (45 deg)
- Key 3  (R1C3): '90'        -> Claw Half Open / Neutral (90 deg)
- Key 4  (R1C4): '180'       -> Open Claw Completely (180 deg)
- Key 5  (R2C1): 'nudge -10' -> Nudge Claw Closed by 10 deg
- Key 6  (R2C2): '135'       -> Claw 3/4 Open (135 deg)
- Key 7  (R2C3): 'nudge +10' -> Nudge Claw Open by 10 deg
- Key 8  (R2C4): 'bark'      -> Play Dog Bark Sound
- Key 9  (R3C1): 'nudge -2'  -> Fine-step Nudge Claw Closed by 2 deg
- Key 10 (R3C2): 'beep'      -> Play Diagnostic Test Tone
- Key 11 (R3C3): 'nudge +2'  -> Fine-step Nudge Claw Open by 2 deg
- Key 12 (R3C4): 'stop'      -> Stop Audio Playback
- Key 13 (R4C1): 'vol -10'   -> Decrease Volume by 10%
- Key 14 (R4C2): 'vol 50'    -> Set Volume to 50%
- Key 15 (R4C3): 'vol +10'   -> Increase Volume by 10%
- Key 16 (R4C4): 'status'    -> Print Device Status


5. BLUETOOTH LOW ENERGY (BLE) SPECIFICATION:
--------------------------------------------------------------------------------
Device Advertised Name:     ESP32S3-Servo
GATT Service (NUS):         6e400001-b5a3-f393-e0a9-e50e24dcca9e
RX Characteristic (Write):  6e400002-b5a3-f393-e0a9-e50e24dcca9e
TX Characteristic (Notify): 6e400003-b5a3-f393-e0a9-e50e24dcca9e

Text Commands Accepted over BLE, Serial, Web, Joystick, and Keypad:
- '0' through '180' (or 'angle <deg>') : Adjust servo position directly
- 'nudge <+/-deg>' (e.g. 'nudge -5')   : Increment or decrement claw position
- 'autoretract <on/off/toggle>'        : Toggle hold-and-snap-to-zero mode
- 'bark'                               : Play embedded dog bark audio
- 'beep'                               : Play diagnostic test tone
- 'stop'                               : Stop audio playback
- 'vol <0-100>' or 'vol <+/-val>'      : Set or adjust speaker volume
- 'pins <bclk> <lrc> <din>'            : Dynamically reassign I2S pins
- 'status'                             : Query angles, volume, and pins
