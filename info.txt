================================================================================
                    YD-ESP32-S3 HARDWARE PINOUT MAPPING
================================================================================

1. SERVO MOTOR WIRING:
--------------------------------------------------------------------------------
Servo Lead      Color (Typical)     YD-ESP32-S3 Pin     Notes
GND             Black / Brown       GND                 Common Ground
VCC             Red                 5V / VBUS           Power from 5V (USB or external supply)
Signal (PWM)    Orange / Yellow     GPIO 4 (GP4)        50Hz LEDC hardware PWM signal


2. HT517 I2S AMPLIFIER WIRING (V1.0.2 SILKSCREEN):
--------------------------------------------------------------------------------
HT517 Pin       Function            YD-ESP32-S3 Pin     Notes
Vin             Power Supply        5V / 3.3V           5V recommended for full 3.1W volume
GND             Ground              GND                 Common Ground
EN              Enable / Mute       NC (Unconnected)    Internal pull-up; leave floating
GAIN            Gain Select         NC (Unconnected)    Floating for default gain
DI2             Serial Data (DIN)   GPIO 12             I2S Audio Data Stream
DIO (DI0)       Bit Clock (BCLK)    GPIO 10             I2S Channel 0 Clock
DI1             Word Select (LRC)   GPIO 11             I2S Left / Right Frame Sync


3. OPTIONAL PDM MICROPHONE WIRING:
--------------------------------------------------------------------------------
Mic Pin         Function            YD-ESP32-S3 Pin     Notes
CLK             Clock               GPIO 42             PDM Clock Output
DAT             Data                GPIO 41             PDM Data Input
VCC             Power               3.3V
GND             Ground              GND
================================================================================
